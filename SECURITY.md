# Security Policy

## Supported Versions

Currently, only the latest release of FPSWatcher is supported with security updates. We encourage users to always use the latest version available on the releases page.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within FPSWatcher, please do not disclose it publicly. 
Instead, please open a draft security advisory on GitHub or report it via private messaging channels if provided by the repository owner.

We take all security issues seriously and will respond to reports as quickly as possible. Once a vulnerability is verified, we will work on a fix and release an updated version with details of the vulnerability properly disclosed.
